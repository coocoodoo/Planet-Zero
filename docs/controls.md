# 操作说明

每行列出一个按键对应的操作。真机方向键统一为 F、X、Z、C，桌面使用上下左右方向键；菜单、设置、帮助和航图沿用各平台的方向键

## 各玩法通用：飞行方向

| 桌面按键 | 真机按键 | 功能 |
| --- | --- | --- |
| ↑ | F | 拉升机头 |
| ↓ | X | 压低机头 |
| ← | Z | 向左转向 |
| → | C | 向右转向 |

## 各玩法通用：飞行动作与视角

| 按键 | 功能 |
| --- | --- |
| Q | 左横滚 |
| E | 右横滚 |
| W | 向上观察 |
| A | 向左观察 |
| S | 向下观察 |
| D | 向右观察 |
| 按住 Shift | 加速，左右 Shift 均支持 |
| 空格 | 切换视角 |
| M | 打开或关闭航图 |
| Alt | 切换悬停，油门归零并保持当前高度；按加速会自动退出悬停 |

WASD 只调整镜头，飞机朝向保持独立。按住时平滑偏转，合成偏角最多 30°，松开后平滑回中，俯瞰、追尾和座舱均可使用

按 Alt 切换悬停模式：引擎油门归零、高度锁定，可自由转向而不会前进，大气层与太空中表现一致。悬停时按加速（Shift）代表开始移动，会自动退出悬停恢复前进；方向键只调整姿态

## 航图

飞行中或暂停页按 M 打开北向上航图，顶部和左侧显示世界坐标，网格区域用 A–H 与 1–8 标识。方向三角键平移地图，中心十字用于选点，金色菱形为已标记目标，青色菱形为虫洞，红色为敌机

| 按键 | 功能 |
| --- | --- |
| ▲ | 向北平移 |
| ▼ | 向南平移 |
| ◀ | 向西平移 |
| ▶ | 向东平移 |
| 1 | 放大航图 |
| 2 | 缩小航图 |
| 3 | 定位下一个虫洞 |
| 4 | 定位飞机 |
| 空格 | 标记十字位置 |
| Enter | 返回飞行并自动导航到标记 |
| M | 返回之前的页面 |

缩放支持 1、2、4、8、16、32、64、128、256、512 倍，最高倍率显示 8 × 8 个世界单位。标记后，飞行画面中央显示全向方位环、距离和高度差；环上箭头的上、右、下、左分别表示目标在机头方向、右侧、身后、左侧。中间三角指示目标在飞机上方或下方。任意方向键可接管自动导航，标记继续保留。跨地图后清除原地图标记

打开航图暂停飞行和任务计时，目标地图继续后台预载。底图按地图、中心和缩放缓存，航图期间暂停三维场景绘制。界面方向提示统一使用 ▲、▼、◀、▶，设备实体按键映射保持 F、X、Z、C，桌面使用方向键

## 桌面显示与鼠标

| 按键或操作 | 功能 | 使用场景 |
| --- | --- | --- |
| F11 | 开启或关闭全屏 | 桌面端 |
| F12 | 依次切换 1、2、4、8 倍输出 | 桌面端 |
| Shift+F12 | 反向切换输出倍率 | 桌面端 |
| 移动鼠标 | 操纵飞行方向 | 飞行中 |
| 点击鼠标左键 | 执行界面操作 | 菜单或 HUD 按钮 |
| 按住鼠标左键 | 开火 | 空战场景 |
| 点击鼠标左键 | 右横滚 | 自由飞行场景 |

功能快捷键在桌面和 Cardputer 共用 `src/keys.rs`。每项功能使用一个主要键位，菜单额外支持方向键。F2 设置页可切换棱面地形、虫洞标签、HUD、声音模式及音量；棱面和标签偏好保存在 `~/.local/share/flight-club/settings-v1.toml`，可用 `FLIGHT_CLUB_SETTINGS` 指定路径

隐藏 UI 后保留座舱实体美术、仪表及场景对象，U 恢复显示；暂停与主菜单始终可打开。眼睛图标按钮可直接点击，三种主要视角均位于右上角，固定追焦的空战界面位于右下角；暂停菜单也提供显隐按钮

桌面高清倍率按宽、高同时增加，真实输出为 320×170、640×340、1280×680、2560×1360，保持相同视野。场景在独立线程绘制，菜单、输入和声音持续响应；HUD 保留像素字体。8 倍计算量较高，适合观景，默认从 1 倍启动。Cardputer Zero 固定使用原生 320×170 输出
