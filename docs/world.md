# 渲染、HUD 与地图

追尾、俯瞰和座舱使用统一的 FPV 风格像素 OSD，信息围绕画面边缘排列，文字加黑色描边。正文使用 5×7 像素字体，速度与高度主数字使用 7×10 像素字体。固定追焦保留原有界面

追尾保留滚动刻度、小地图、GPS 坐标、电压和信号数值。俯瞰保留航向、速度、高度、离地高度、计时、电量、信号格和左下角小地图。座舱将速度与高度放在风挡两侧，中央保留青色描边准星和俯仰标线，实体仪表盘继续显示动态仪表

追尾视角的完整布局如下

| 位置 | 显示内容 |
| --- | --- |
| 顶部中央 | 滚动航向罗盘、方位刻度和当前航向角 |
| 左侧 | 速度数值与刻度，单位为游戏世界单位每秒 |
| 右侧 | 高度数值与刻度、相对当前地面的 AGL 高度 |
| 左上角 | 本次飞行累计时间、天气和飞行状态图标 |
| 右上角 | 真机电量百分比、电池电压、充电状态与 Wi-Fi RSSI |
| 左下角 | 北向上的极简小地图，标记飞机、虫洞、任务目标和敌机 |
| 下沿 | 游戏内 GPS 坐标、当前任务与武装状态 |

LOC 使用当前地图内的 X/Y 坐标，按 4096 单位周期显示，跨地图时切换到目标地图坐标。小地图以飞机为中心显示约 960 × 800 单位范围，地形底图按地图缓存。M 可打开完整航图。太空显示空间高度，AGL 使用占位符

追尾战斗界面的护盾、能量、武器、NOVA、超载、任务进度、护航或 Boss 耐久、僚机支援和分数集中在下沿。中央保留飞行视野，虫洞名称使用小号描边字体

Cardputer Zero 通过 `/sys/class/power_supply/` 自动发现 BQ27220 电池，读取 `capacity`、`voltage_now` 和充电状态对应的 `uevent` 字段；电压从微伏转换为伏。Wi-Fi 信号读取 `/proc/net/wireless` 的 RSSI，追尾视角在信号格右侧显示 dBm 数值，代表设备无线网络信号

硬件数据在独立线程每秒采样一次，渲染线程读取缓存。单项读取失败或采样超过 3 秒未更新时显示占位符；桌面版使用占位符。飞行时间随任务推进，暂停和打开航图时停止计时。U 控制整套 HUD 的显示

月球与太空显示星空图标，使用无大气星空，关闭降水和大气雾。月球保留离地保护；太空使用立体空间，高度活动范围为 -240 至 900，座舱雷达显示附近空间实体。太空按 4096 单位周期布置飞船、卫星和小行星，虫洞随本次探索网络布置

虫洞入口采用始终面向玩家视角的圆形面片，光环按目的地配色：沙漠金黄、雪山与冰山银白、群岛青色、高地绿色、峡谷赭橙、城市紫色、火山红色，黄昏与夜晚再进行轻微色调匹配，从任意方向靠近中心区域即可抵达另一端。窗口按玩家相机的位置和方向实时渲染出口场景，前景物体可遮挡入口。外部引力透镜的影响半径为入口的 2.25 倍，包含径向拉伸、旋转扰动、暗内缘、明亮光子环和流动辉光。窗口内部对目标场景施加径向波纹、旋转扰动和半透明着色层，靠近穿越时逐渐淡出。追尾与座舱按相机抵达入口的时机切图，主机、相机和尾迹共享同一个空间变换，保持相对位置与运动连续；俯瞰视角用 0.75 秒从入口圆圈向四周扩张目标地图，直至覆盖整个画面。俯视、追尾和座舱共用画面入口与实际空间入口检测，预览和穿越使用一致的相机变换。穿越保留速度、姿态与相机相对方向。俯瞰转场保持全部僚机的相对位置与尾迹，返回入口、标签及加载圆环持续隐藏，直到入口及外围扭曲范围完整离开画面，再恢复正常显示。追尾与座舱视角中，已经进入窗口的僚机随之通过，其余僚机延迟从出口内部出现，并从玩家身后追赶归队。主机和已经过门的僚机将尾迹一同映射到出口，延迟追赶的僚机重新产生尾迹；穿越播放跃迁音效；0.8 秒冷却防止连续回跳，拾取和检查点检测按出口位置继续

十二类地图通过随机虫洞网络连接，每张地图最多两个出口，入口位置、高度和目标地图随本次启动生成，往返连接保持一致。自由飞行中 `3` 每次只替换一处入口，在前方 680–800 单位生成，保留另一条自然连接，整个地图网络保持连通。新入口立即请求预载目的地，玩家飞抵入口前留出加载时间。F2 可关闭入口名字标签；虚线环表示预载，准备完成后显示对端实时景色


跨地图保留装备、分数、关卡阶段和编队，任务检查点、敌机与补给按出口变换位置并适应地形。当前地图外缓存两个目的地区域，按距离与朝向优先加载，进门时直接接管已加载地图，保留可返回的原图。演示和菜单背景同样提前预载，缓存未就绪时显示目的地加载页面。近处入口提前写入深度遮挡，裁剪当前地图被遮住的区域，对端按窗口可见列和视锥绘制；窗口采用一层渲染，孔径按半分辨率渲染，设备端每帧约省 3ms

探索提示：自由飞行选择 SPACE 后，保持初始航向和约 140–150 高度，前方约 650 单位处有一个蓝色入口。键盘游玩时可用 7 关闭自动转向，体感游玩时保持设备中立。地图选择适用于四种模式；选择 STAGE 或进入下一关会加载原有六关战役对应的地图

基地、飞船、出生点、撞击坑数量及虫洞位置配置保存在 `content/maps/moon.toml` 和 `content/maps/space.toml` 的 `cosmic` 区域。虫洞实时窗口采用一层对端渲染，保持原生像素分辨率

球面与地表共用预载地图的高度、材质和地形渲染器，通过连续改变曲率半径，将球面展开为局部平面，升空时反向收拢。远处地球显示海洋、大陆和云带，接近后逐渐呈现目标区域细节。过渡随实际高度推进；相机、飞机、僚机与尾迹统一变换坐标，交接保留观察偏角、速度和正在进行的特技，天空与云层随高度渐变。返回地面时继续使用正常飞行操作，也可中途重新拉升返回太空。此实现基于 Rust CPU 软件渲染，采用曲率三角函数缓存、材质查表、共享地图内存和多核分列渲染

行星表面 2200 单位范围内关闭虫洞窗口绘制与穿越；进出行星时，将当前地图的出入口放到身后 3200/3700 单位以外，并避开行星近邻范围。暂停、帮助和航图会冻结过渡；过渡期间保留方向操控、镜头观察和符合安全高度要求的特技。轨道探索适用于自由飞行，战役与导演演示保持各自的关卡流程


普通区域的保护基准为 **地平面 + 28 个世界单位 + 低矮建筑平均高度**，全图使用一致的基础高度。高山和高楼向周围形成约 10° 的缓坡包络，航线根据当前速度与转弯率提前预测 8 秒；峡谷按飞机下方谷底 + 28 计算，并预测前方 5 秒路径。预测路径接近侧壁或峡谷出口时提前爬升，下降接近谷底时平滑减速。普通飞行的垂直加速度上限为 24 单位/秒²，爬升和下降速度均限制为当前速度的 40%；实际防撞边界为机身周围地形加 8 单位，允许安全间距随小坡起伏变化。即将进入陡壁而爬升尚未完成时，限制本帧水平前进量，保持高度连续；僚机保持最低间距

低空俯仰限制在约 ±32°，松开操纵后平滑恢复水平。达到安全高度后，持续按住对应俯仰方向 **3 秒**，松开后在 **0.3 秒**内再按两次同方向键，触发对应方向的完整 360° 筋斗。▲ 对应内筋斗，▼ 对应外筋斗；左右方向键用于转向，横滚使用 Q 或 E。长按方向与持续 IMU 倾斜用于普通飞行。HUD 保留必要飞行数据，天气、演示、体感与自动巡航使用图标，去除底部快捷键条、LOOP 高度和计时提示。筋斗期间，追尾和座舱相机、编队与飞行轨迹一起旋转；动作开始后松开操纵仍会完成整圈。安全高度根据地图最高地形、建筑和载具最大速度计算。横滚需要高于地图最高障碍 80 单位；太空始终允许特技。洞穴内按洞顶约束飞行高度

`8` 开启导演演示。特技包含爬升、滚转、八字绕飞、俯冲拉起、僚机分离、螺旋爬升和高速通场。96 秒镜头周期中，追尾约 65%、俯瞰约 21%、座舱约 8%、固定追焦约 6%，通过连续权重平滑移动镜头。第 28 秒和第 70 秒进入跃迁段，目标地图准备完成后在镜头背后放置入口，飞机平滑转向，追尾镜头随转向带出虫洞后飞入，加载较慢时延后放置。跨地图预览与实际到达使用同一组天气和时段。方向键可以接回飞行控制；7 切换自动巡航；真机 I 切换体感

地形各视角统一使用三角网格与自适应细节层级，设置中的棱面开关只改变光照风格，保持网格、纹理和视角处理一致。积雪中的蓝色冰材质集中为连续区域；网格边界用定点覆盖规则处理共享边缘，俯瞰采用线性深度插值

座舱的舱盖、仪表板、前部和后框四层合成稳定底图，按位移、天气和时段缓存；阳光扫过、雷达、仪表、操纵杆和玻璃 HUD 独立叠加。遮挡在旋转后的场景画布中按像素标记，地形、云、建筑与飞机共享深度裁剪，仪表绘制保留层间遮挡关系


云底参考周围普通地形动态抬升，避开高山和建筑占据的区域，高峰可以高于云层。洞穴、石拱和岩壁使用世界坐标纹理，包含岩层、裂纹和颗粒，随视角保持稳定
