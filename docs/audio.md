# 配乐与音效

声音由 Rust 实时合成，使用方波、锯齿波、三角波、正弦波、FM 音色和噪声发生器。乐谱中的主旋律、和声与段落分别编写，低音、琶音、鼓组和过门按乐谱编排。输出为 48 kHz 立体声，设备使用 16 位 PCM，保留芯片音乐的音色并提供干净的动态范围

配乐按“场景 + 地图”选曲，共 27 首原创曲目。每张地图有一首与地标和地区风格呼应的专属主题，时间段与天气通过分层编配表达；其他场景各有自己的曲库，一首完整播完后在同一曲库里随机换下一首，不重复当前曲目。每次启动用时间播种，开场曲目也不固定

场景切换在下一拍开始交叉淡化：旧曲沿原有节拍继续演奏并在 2.6 秒内淡出，新曲在 1.4 秒内淡入，并跳过前奏直接从主题段进入；通关与失败在 0.9 秒内完成切换并从开头播放。穿越虫洞到达有专属曲目的地图后，需要在新地图停留 8 秒且当前曲目已播放 25 秒才换曲，快速往返虫洞时保持原曲。轨道推进点火后飞机沿弧线爬升，从点火到入轨约 24 秒；飞过 1000 米后叠加上升声部，持续约 17 秒，下降段继续播放太空配乐，着陆后回到地表曲目。一首完整播完后从下一首的开头播放；结算曲播放完整段落后循环后八小节。暂停降低配乐音量与高频，恢复后继续当前进度

乐谱除旋律与和声外，可以为每首曲目指定主旋律音色、低音型（drive、cruise、eighths、gallop、walk、long、pedal）、鼓组（drive、steady、four、half、break、march、tribal、shuffle、none）、琶音型、摇摆量、铺底音量和副旋律，`cues` 声明曲目所属场景，`maps` 声明专属地图

低护盾或 Boss 半血时加入紧张节奏，超载期间加入高音琶音层。引擎声音随机型变化：猎鹰均衡，飞镖高亢，阿特拉斯低沉厚重，黄蜂尖锐，纸飞机几乎只有风声。轨道推进时，火箭低频轰鸣从 600 米开始渐强，到 1000 米达到最大，并叠加随高度升高的气流哨音，进入真空后风噪消失、配乐变暗

每首曲目按主旋律、副旋律、铺底、低音、琶音、鼓、镲片分层编配，混音器按情境实时调节各层音量，而不是换曲：

- 探索：白天全编制；黄昏鼓和琶音减弱；夜晚去掉鼓、琶音变稀、主旋律收小、铺底加厚，配乐更暗、混响更大
- 天气：下雪去掉鼓并落下零星高音钟声，雷暴隔小节一声低沉定音鼓，下雨铺底加厚，起雾和沙尘让主旋律与音色更闷；同时加入雨声、时强时弱的风声，闪电后响起延迟的雷声
- 升空：飞过 1000 米后在探索配乐上叠加上升声部，镲片加密、底鼓按拍、琶音随高度逐级升高，接近入轨时加入小鼓滚奏
- 竞速与金币：越接近终点或连击越高，编配越完整；最后四分之一赛程与金币最后 15 秒加入冲刺层
- 空战：巡逻时只保留铺底与律动，敌机逼近、弹幕密集、开火或护盾告急时逐层加入鼓、琶音、主旋律与副旋律；Boss 战全编制

音效覆盖：
- 自机：加力点火、翻滚与筋斗、悬停与自动开火开关、视角切换、受击、坠毁
- 武器：五种武器各有独立音色，切换武器时按武器播放不同音高的上膛声，NOVA、超载、拾取与强化
- 敌机：普通敌机与重型敌机（Boss、地面炮台、重型机）的开火声，敌机贴身掠过的呼啸，擦弹提示，命中、普通与 Boss 爆炸，敌机来袭警报，Boss 警报
- 飞行与太空：达到入轨高度的提示音、轨道推进点火、冲出大气层的音爆、入轨和弦、再入大气的摩擦轰鸣、着陆和弦、虫洞穿越
- 菜单操作、倒计时、金币连击、检查点、阶段完成

音乐、音效分别混音，警报与大爆炸短暂压低配乐。方波和锯齿波使用 PolyBLEP 抑制混叠，振幅包络和音量变化平滑处理，旋律具有立体声延迟，输出经过直流消除和峰值限制。音效限频避免密集命中重复堆积，实时声部上限为 64

- `F9`：全部声音 → 仅音乐 → 仅音效 → 静音
- `F2`：打开设置，选择 VOLUME 调整音量，每档 10%，初始 70%
- 左方向：选中 VOLUME 时降低音量
- 右方向：选中 VOLUME 时提高音量
- 设置页显示当前声音模式与音量，系统音量继续由设备系统管理
- 静音期间音乐时钟持续运行，恢复时衔接当前段落

音乐文件位于 `content/music/*.toml`，包含音名、十六分音符时值、和弦和段落编排；`src/audio/` 按振荡器、乐谱编译、音效、混音与平台输出拆分。修改乐谱后重新构建。游戏运行时直接合成音频，配乐无需打包为 WAV 或 MP3

桌面 macOS / Windows 使用 CPAL，Linux 与 Cardputer Zero 通过 `pacat` 输出到 PipeWire / PulseAudio。设备安装包依赖 `pulseaudio-utils`，音频线程与渲染独立，以 10 ms 分块输出并请求 60 ms 缓冲

```sh
# 导出全部配乐、110 秒场景串烧和音效试听为 WAV
cargo run --release --no-default-features --bin flight-club-audio -- captures/audio

# 在设备上测量合成器，或关闭音频进行画面对照
flight-club-cardputer --audio-benchmark 15
flight-club-cardputer --mode combat --audio off --frames 450
```

0.6.0 真机合成压力测试：15 秒 Boss 配乐、超载、加速与密集音效耗时 2.054 秒，约占一个 CPU 核心的 13.69%，优化前为 16.10%，同时发声峰值 20。火山雷雨座舱显示对照各运行 450 帧，关闭声音平均 29.93 FPS，开启声音平均 29.93 FPS，开启声音时绘制平均 18.84 ms、P95 19.49 ms，游戏进程峰值内存比关闭声音增加约 1.4 MiB

真实 BMI270 与声音同时开启的完整关卡回放提交 5,235 帧，用时 174.952 秒，约 29.92 FPS；完成静音恢复、第一关 136.47 秒通关、强化选择与第二关护航，切图期间进程峰值内存约 89.8 MiB。设备输出音频通过 PipeWire 输出监视器录取，已验证菜单 → 巡航 → 空战 → Boss → 通关 → 下一关的实际切换。录音中静音模式的 PCM 为零，恢复后正常发声；战斗期间未出现 10 ms 及以上的数字静音断段，削波采样数为零
