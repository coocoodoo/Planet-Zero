# 美术素材

PNG 是可编辑的素材源，`cargo build` 自动运行根目录的 `build.rs`，将程序使用的数据写入 Cargo 的 `OUT_DIR`

- `cockpit/<载具>/*.png`：342 × 192 像素，RGBA 或索引色 PNG，透明度为 0 或 255，每张最多 256 种颜色，编译时转为调色板和连续像素游程，运行时在加载座舱时展开，每种载具使用舱盖、仪表盘、操纵机构三层，舱盖包含固定连接的内外框
- `vehicles/falcon.png`：34 × 598 像素，13 个 34 × 46 的体素切片从上到下排列，对应模型的高度层，透明像素表示空体素，实色使用 `src/render/palette.rs` 中的 `JET` 材质色，编译时恢复材质编号

保持原生像素尺寸，关闭编辑器的平滑缩放和边缘抗锯齿；放大预览使用最近邻插值
